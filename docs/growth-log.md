# TokenBrief — growth log (acquisition proof)

This file is what we show Anna if usage is ever questioned. The Founding Builder Program rules
require builders to "be able to show acquisition/marketing proof", and they suspend apps with
suspicious usage (7-day appeal window). One row per post, added the same day with
`pnpm log:post`, plus a screenshot of the post in `docs/evidence/posts/`. Never write a number
you cannot screenshot: a log with gaps is more credible than one with round guesses.

Rules that never bend: no giveaways, no "run it to win", no paid runs, no asking friends to run
it repeatedly or to create extra accounts. `pnpm log:post` refuses rows with incentive wording.
